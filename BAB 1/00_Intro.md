# BAB 1: Pengenalan Pemrograman Python

Halo! Selamat datang di Bab Pertama.

Sebelum kamu mulai melakukan kegiatan wajib seorang programmer yaitu menulis kode (coding), sangat penting untuk memahami apa yang sedang kamu pelajari saat ini. Dengan demikian, kamu akan lebih mudah memahami dan mencerna segala materi ke depannya.

Di Bab ini, fokus utama kamu adalah berkenalan dan memahami konsep dasarnya. Jika tahap ini dilewatkan, pemahaman kamu tentang fundamental Python tidak akan kokoh.

## Tujuan Belajar Bab Ini

Setelah selesai membaca semua materi di atas, diharapkan kamu bisa:

* Menjelaskan apa itu Python dengan bahasa sederhana.
* Mengetahui asal-usul nama Python (bukan dari nama ular).
* Memahami alasan Python sangat populer di dunia kerja industri.
* Mengerti konsep "Library" atau pustaka tambahan secara logika.
